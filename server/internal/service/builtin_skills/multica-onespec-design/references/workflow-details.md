# OneSpec Design Workflow

输入和输出均在本地变更目录：

```text
onespec/changes/<feature-name>/proposal.md
onespec/changes/<feature-name>/specs/*.md
onespec/changes/<feature-name>/design.md
```

设计完成后进入 `$onespec-task <feature-name>`。外部平台同步不是设计流程的一部分，且不得因为目录名或历史记录自动执行。
